# verb_person_stems.txt — источник, лицензия, формат

Пары форм глагола 1-го и 2-го лица единственного числа изъявительного наклонения («работаю работаешь»), записанные
как основа и образец окончаний: «работа» + образец «ю / ешь». Образцов 50, пар 30 925, файл 242 325 байт (UTF-8).
Формат и чтение — `RetellTable.readStems` (`app/src/main/java/com/uroboros/memory/nav/RetellTable.kt`).

Получены из словаря OpenCorpora (через морфологический анализатор pymorphy3) — только эти формы, без остального словаря.

- Словарь OpenCorpora: http://opencorpora.org — лицензия **CC BY-SA 3.0** (https://creativecommons.org/licenses/by-sa/3.0/).
- Словарь OpenCorpora восходит к словарю АОТ (http://aot.ru) и «Грамматическому словарю русского языка» А. А. Зализняка.

Файл — производное от словаря и распространяется под той же лицензией (CC BY-SA 3.0). Код приложения, который его
читает, этой лицензией не затрагивается.

## Как пересобрать

1. Список пар (по паре в строке через пробел) из pymorphy3: для каждого глагола словаря — формы 1-го и 2-го лица
   единственного числа изъявительного наклонения.
2. Файл основ из списка пар — тем же кодом, что читает таблицу:
   `RetellTable.stemsFileLines(RetellTable.parse(строки пар))`, строки — через перевод строки.
3. Сверить число пар (выше) и прогнать тесты `RetellTableTest` и `PersonFormTest`.
