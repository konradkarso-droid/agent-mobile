# verb_person_pairs.txt — источник и лицензия

Пары форм глагола 1-го и 2-го лица единственного числа изъявительного наклонения («работаю работаешь»), по паре в строке, через пробел, UTF-8.

Получены из словаря OpenCorpora (через морфологический анализатор pymorphy3) — только эти формы, без остального словаря.

- Словарь OpenCorpora: http://opencorpora.org — лицензия **CC BY-SA 3.0** (https://creativecommons.org/licenses/by-sa/3.0/).
- Словарь OpenCorpora восходит к словарю АОТ (http://aot.ru) и «Грамматическому словарю русского языка» А. А. Зализняка.

Файл — производное от словаря и распространяется под той же лицензией (CC BY-SA 3.0). Код приложения, который его читает, этой лицензией не затрагивается.
