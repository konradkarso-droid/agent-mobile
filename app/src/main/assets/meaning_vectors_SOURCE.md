# meaning_vectors.bin — источник, лицензия, формат

Векторы начальных форм для прибора «смысл» (`app/src/main/java/com/uroboros/memory/nav/Meaning.kt`): для
каждой начальной формы — 300 чисел, её место среди других слов по смыслу. Формат и чтение —
`MeaningVectors.read` (`app/src/main/java/com/uroboros/memory/nav/MeaningVectors.kt`).

Начальных форм 63 334; файл 7 164 144 байт, sha256 `01ef11a199923072eda85ed814212ec4ead24ea7c523a7340fa3e5d2c8cf818e`.

## Откуда

Получен из векторов слов Navec (`navec_hudlit_v1_12B_500K_300d_100q.tar`, 500 тысяч слов, обучены на
художественной литературе): https://github.com/natasha/navec — лицензия **MIT**
(https://github.com/natasha/navec/blob/master/LICENSE).

Что взято и как сжато — против исходных 50 МБ:

- **только начальные формы** (у pymorphy3 2.0.6 со словарём pymorphy3-dicts-ru 2.4.417150.4580142 — те же, что
  у словаря начальных форм): форму слова приложение приводит к начальной своим словарём, векторы форм не нужны;
- **только употребительные**: частота лексемы по wordfreq 3.1.1 (https://github.com/rspeer/wordfreq; шкала
  zipf, берётся самая частая форма) выше 2,0. wordfreq решает только «брать слово или нет», его данных в файле
  нет. На выгрузке памяти 03.11.2026 вектор есть у 95,4% значимых слов (без отбора по частоте — 96,0%);
- **словарь** — с общими началами соседних слов, как основа и окончание у наших словарей;
- **коды векторов — те же, что у Navec**: 100 кусков, у каждого 1 байт — номер одного из 256 образцов.
  Пережимать сильнее не стали: при 50 байтах на слово прибор выбирает на выгрузке другую запись в 30% ходов.

Файл — производное от Navec и распространяется под той же лицензией (MIT).

## Как пересобрать и сверить

1. `pip install navec==0.10.0 pymorphy3==2.0.6 pymorphy3-dicts-ru==2.4.417150.4580142 wordfreq==3.1.1`,
   скачать `navec_hudlit_v1_12B_500K_300d_100q.tar` по ссылке из README Navec.
2. `python3 docs/slovar/meaning_build.py navec_hudlit_v1_12B_500K_300d_100q.tar meaning_vectors.bin`
   (около полутора минут). Сборка повторяемая: тот же sha256, что выше.
3. Прогнать `MeaningVectorsTest` и `MeaningTest`.
